# tests/

Put your **tests** here — small pieces of code that automatically check your real
code (in `src/`) does what you expect.

- Test files are usually named `test_*.py` (e.g. `test_helpers.py`).
- Run them from the project root with:
  ```
  pytest
  ```
- A passing test suite is your safety net: change your code, re-run the tests,
  and instantly see if you broke anything.
